## Descripción del Repositorio

Este repositorio contiene la solución a 5 problemas prácticos desarrollados en Python utilizando estructuras de control condicionales (`if`, `elif`, `else`).

---

## Programas Incluidos

1. **Clasificación de Triángulos (`1_triangulos.py`)**: Solicita las tres longitudes de los lados de un triángulo e indica si es equilátero, isósceles o escaleno.
2. **Año Bisiesto (`2_bisiesto.py`)**: Evalúa un año ingresado para determinar si es bisiesto según las reglas del calendario.
3. **Conversor de Calificaciones (`3_calificaciones.py`)**: Convierte una calificación numérica (0 a 100) a su equivalente en letra (A, B, C, D o F).
4. **Comparación de Tres Números (`4_comparacion_numeros.py`)**: Pide tres números al usuario y determina cuál es el mayor y cuál es el menor.
5. **Tarifa de Entrada (`5_tarifa_entrada.py`)**: Calcula el costo de la entrada a un parque basándose en la edad ingresada.
